# Lumen (Arbeitstitel) — Social Portal

Mischung aus dem Besten aller großen Social Networks. Finaler Name folgt.

## Konzept
- [x] Research: Instagram, TikTok, Discord, Reddit, Bluesky, Threads, LinkedIn, BeReal, Mastodon
- [x] Unique DNA: Lenses + Circles + Moments + Sparks + Collectives + Signal-Score
- [x] Arbeitstitel „Lumen“, Branding austauschbar

## Backend
- [x] In-Memory Social Store mit Seed-Daten (ohne DB-Abhängigkeit)
- [x] tRPC Router `social.*` (Feed, Moments, Circles, Collectives, Messages, Explore)
- [x] Erklärbare Lens-Ranking-Gewichte + „Warum?“-Reasons
- [x] Vitest für Store-Logik

## Frontend
- [x] Landing (Brand-first Hero)
- [x] Feed mit Lens-Switcher, Moments, Compose
- [x] Sparks, Circles, Collectives, Explore, Direct, Profile, Post-Detail
- [x] Design-System: Syne + Manrope, Mist/Ink/Coral/Tide
- [x] Motion: Hero-Rise, Lens-Pill, Post-Appear, Moment-Viewer
