# Code Assist — Ordner NachtBlau-Hub

Diesen **Ordner** in Code Assist öffnen. Daraus die APK bauen.

- Ordner im Repo: `codeassist/NachtBlau-Hub/`
- ZIP (entpackt als Ordner `NachtBlau-Hub`): `NachtBlau-Hub.zip`

In Code Assist:

1. ZIP herunterladen und entpacken **oder** den Ordner `NachtBlau-Hub` direkt öffnen.
2. Auftrag: `./gradlew assembleDebug`
3. APK: `app/build/outputs/apk/debug/app-debug.apk` → `NachtBlau-Hub.apk`

Die App lädt live https://launcher.nachtblau-interactive.com/android.html
