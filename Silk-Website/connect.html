Silk Connect

Alte Apple-Geräte bleiben nutzbar – als Begleiter zu deinem Silk-PC.

Wichtig: Silk läuft nicht nativ auf iPhone/iPad. Connect verbindet dein Apple-Gerät per Browser und Remote-Desktop mit Silk – so wird alte Hardware wieder sinnvoll einsetzbar.

So funktioniert's

1. Silk-PC einrichten

silk-connect setup
silk-connect status

2. iPad/iPhone verbinden

Safari → URL aus status → Pairing-Code → „Zum Home-Bildschirm“.

3. Remote-Desktop

flatpak install flathub com.rustdesk.RustDesk
silk-connect remote

4. Kiosk (altes iPad)

Dauer-Display für Küche/Kalender: silk-connect dashboard

Funktionen im Dashboard

  • Remote-Desktop zum Silk-PC (RustDesk, Parsec, Moonlight)
  • Datei-Sync (Dropbox, Nextcloud, Rclone)
  • Medien-Fernbedienung
  • Hilfe & FAQ für Umsteiger
  • Offline-fähige PWA (Service Worker)

Diagnose

silk-doctor
silk-connect pair
