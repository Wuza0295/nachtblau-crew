Silk – Installation

Silk ist das Betriebssystem. Du brauchst kein Aurora.

Empfohlen: Installer-ISO (VirtualBox / USB)

  1. Release öffnen: silk-media-latest
  2. Alle Silk-Installer-x86_64.iso.part* + reassemble.sh + .sha256 laden
  3. bash reassemble.sh → Silk-Installer-x86_64.iso
  4. VirtualBox: neue EFI-VM, Name Silk, Betriebssystem Linux (64-bit) – nicht Fedora
  5. ISO einbinden, Silk installieren, nach Login silk-setup

Optional: schon Bootc (AMD / Intel)

sudo bootc switch --enforce-container-sigpolicy ghcr.io/wuza0295/silk:latest
sudo systemctl reboot

NVIDIA:

sudo bootc switch --enforce-container-sigpolicy ghcr.io/wuza0295/silk-nvidia-open:latest
sudo systemctl reboot

Erstlogin

silk-setup → Stil wählen → Essentials → optional Gaming → silk-welcome

Wichtige Befehle

silk-welcome
silk-install datei.exe
silk-desktop mac
silk-wallpaper list
silk-update
sudo bootc upgrade

Probleme?

  • sha256sum -c → Dateiname muss Silk-Installer-x86_64.iso heißen (kein dist/)
  • VirtualBox zeigt Fedora → VBoxManage modifyvm Silk --ostype Linux26_64
  • NVIDIA schwarzer Bildschirm → silk-nvidia-open Image

Silk ist kein macOS/Windows. Community-Projekt der Nachtblau Crew.
