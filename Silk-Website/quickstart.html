Silk – Installation in 5 Minuten

Voraussetzung: PC mit UEFI, Internet. Start von Universal Blue (Fedora Atomic, KDE Plasma) oder anderem Bootc-System.

1. Image wählen

  • AMD / Intel: ghcr.io/wuza0295/silk:latest
  • NVIDIA (Turing/16xx+): ghcr.io/wuza0295/silk-nvidia-open:latest

2. Installieren

AMD / Intel:

sudo bootc switch --enforce-container-sigpolicy ghcr.io/wuza0295/silk:latest
sudo systemctl reboot

NVIDIA:

sudo bootc switch --enforce-container-sigpolicy ghcr.io/wuza0295/silk-nvidia-open:latest
sudo systemctl reboot

3. Erstlogin

silk-tour startet automatisch: Stil wählen → Apps → Windows-.exe → optional Gaming → Startzentrum.

4. Wichtige Befehle

silk-tour --center
silk-welcome
silk-ready status
silk-install datei.exe
silk-desktop --ask
silk-update
silk-tips
sudo bootc upgrade

Probleme?

  • bootc switch fehlgeschlagen → --enforce-container-sigpolicy setzen
  • NVIDIA schwarzer Bildschirm → silk-nvidia-open Image nutzen
  • Zurück zum vorherigen Bootc-Image → sudo bootc switch <dein-vorheriges-image> (z. B. Universal-Blue-KDE-Tag aus silk/silk.env)

Silk ist kein macOS/Windows. Community-Projekt der Nachtblau Crew.
