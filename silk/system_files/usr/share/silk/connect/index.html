📌 Kiosk-Modus (altes iPad)

Safari → Teilen → „Zum Home-Bildschirm“. Dann: Einstellungen → Anzeige → Automatisches Sperren → Nie (nur wenn das Gerät dauerhaft als Display dient).

Hinweis: Silk läuft nicht nativ auf iPhone/iPad. Dieses Dashboard verbindet dein Apple-Gerät mit einem Silk-PC – so bleibt alte Hardware nutzbar.
