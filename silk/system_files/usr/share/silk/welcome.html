Willkommen bei Silk

Kurzhilfe für den Umstieg von Windows oder macOS. Du kannst dieses Fenster jederzeit mit silk-welcome öffnen.

Mac / MacBook

  • silk-hardware status – PC vs. Intel-Mac vs. Apple Silicon
  • silk-hardware hints – was geht, was nicht
  • Wechsel von macOS auf PC: silk-desktop mac, silk-install datei.dmg
  • Linux auf dem MacBook: Fedora Asahi Remix (nicht Silk)

GPU (AMD / Intel / NVIDIA)

  • silk-gpu status – erkannte Grafikkarte
  • silk-gpu hints – Kernel-Args & Image-Empfehlung
  • NVIDIA: bootc switch …/silk-nvidia-open:latest

Hintergründe (20× Desktop + 20× Sperrbild)

  • silk-wallpaper list – alle Varianten anzeigen
  • silk-wallpaper list mac / list win – nach Stil filtern
  • silk-wallpaper set mac 03 – Ventura Dawn (Mac)
  • silk-wallpaper set win 14 – Win10 Hero (Windows)
  • silk-wallpaper random win – zufällig wechseln

Desktop-Stil

  • silk-desktop mac – Menüleiste + Dock
  • silk-desktop windows11 – zentrierte Taskleiste
  • silk-desktop windows10 – klassische Taskleiste
  • silk-desktop --ask – Auswahl erneut

Tastatur (Umgewöhnung)

  • Windows-Taste / Mac-⌘ → hier oft Meta (Windows-Taste)
  • App wechseln: Alt+Tab
  • Screenshot: Spectacle (Taskleiste) oder Meta+Shift+S (je nach Layout)
  • Terminal: Konsole im Startmenü

Programme wie vorher

  • Windows .exe → Linux-App oder Wine/Bottles
  • Mac .dmg/.app → Linux-Gegenstück
  • .AppImage → Flatpak oder Gear Lever / ~/Applications
  • .flatpak / .flatpakref → direkt installieren
  • .deb / .snap → Flatpak bevorzugt, sonst Ubuntu-Box
  • .rpm → Flatpak oder Fedora-Box / rpm-ostree
  • Alltag: wird beim ersten Start eingerichtet · Gaming: optional

Dateien & USB

  • Windows-Sticks (NTFS / exFAT) sollten automatisch mounten
  • Netzwerkfreigaben (SMB): Dolphin → Netzwerk
  • Backup: Pika Backup (nach Essentials-Setup)

Updates

  • Alles bequem: silk-update (Apps + Listen vom Git-Repo)
  • System komplett: silk-update --full (danach neu starten)
  • Manuell: sudo bootc upgrade · flatpak update
