# Apple Silicon (M1 / M2 / M3 / M4 MacBook, Mac mini, iMac, Mac Studio)
#
# Status: Silk läuft hier NICHT (andere CPU-Architektur + Apple-Treiber nötig)
#
# Warum:
#   - Apple Silicon = ARM64 mit Apple-spezifischem Boot, GPU, WLAN, Audio
#   - Silk nutzt ghcr.io/ublue-os/aurora:stable (PC-Image, kein Asahi-Kernel)
#   - Mesa AGX + Asahi-Firmware fehlen in Aurora
#
# Alternative für Linux auf dem Mac:
#   Fedora Asahi Remix: https://fedora-asahi-remix.org/
#   (Installation über Asahi Linux Installer in macOS)
#
# Zukunft:
#   Wenn Fedora Asahi Remix atomic/bootc stabil ist, ist ein Silk-Image
#   „silk-asahi“ denkbar – analog zu silk-nvidia-open. Noch nicht verfügbar.
#
