# Desktop-Gewohnheiten (Mac / Windows)

Beim Stil-Wechsel (`silk-desktop mac|windows11|windows10`) setzt Silk neben Optik auch **vertraute Bedienung**.

## Mac (`silk-desktop mac`)

| Gewohnheit | Silk |
|------------|------|
| Menüleiste oben + Dock | ✅ Layout |
| Fensterknöpfe links | ✅ |
| Spotlight | Meta+Leertaste (KRunner) |
| Fenster schließen | Meta+W |
| Minimieren | Meta+M |
| Mission Control | Meta+F3 · Hot Corner oben links |
| Desktops | Meta+Ctrl+←/→ |
| Screenshot | Meta+Shift+3 / 4 |
| Natürliches Scrollen | ✅ |
| Finder-ähnlich | Dolphin mit Pfadzeile |

## Windows 11 / 10

| Gewohnheit | Silk |
|------------|------|
| Taskleiste unten (zentriert / links) | ✅ |
| Fensterknöpfe rechts | ✅ |
| Start | Meta |
| Ausführen | Meta+R |
| Explorer | Meta+E (Dolphin) |
| Desktop zeigen | Meta+D |
| Andocken | Meta+←/→ |
| Snipping | Meta+Shift+S |
| Zwischenablage | Meta+V |
| Sperren | Meta+L |
| Einstellungen | Meta+I |

## Neu anwenden

```bash
silk-desktop mac          # Optik + Gewohnheiten
silk-apply-habits mac     # nur Tasten/Verhalten
cat ~/.config/silk/habits-cheatsheet.txt
```

Kurzübersicht landet in `~/.config/silk/habits-cheatsheet.txt`.
