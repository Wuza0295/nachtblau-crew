Silk

Linux für Umsteiger von Windows und macOS – mit wählbarer Mac- oder Windows-inspirierter Optik.

ISO laden Quickstart
Hinweis: Silk ist kein macOS und kein Windows. Silk ist kein offizielles Produkt von Apple, Microsoft, Fedora oder Universal Blue. Optik ist inspiriert von Open-Source-Themes. Marken gehören ihren jeweiligen Inhabern. Software ohne Garantie („AS IS“).

Was Silk kann

🖥 Desktop-Stil

Mac (Menüleiste + Dock), Windows 11 oder Windows 10 – beim Erstlogin wählbar.

📦 Smart-Installer

.exe, .apk, .dmg, .app, .deb, AppImage – Flatpak zuerst, sonst Wine/Waydroid.

🎮 Gaming

Steam, Heroic, Discord, OBS, Minecraft, MangoHud – optional beim Setup.

⚡ GPU

AMD, Intel und NVIDIA (nvidia-open Image für Turing/16xx+).

🔄 Updates

silk-update für Apps, bootc upgrade für das System.

🌍 Wechsler

NTFS/exFAT, SMB, Hilfe via silk-welcome, 20 Mac/Win-Hintergründe.

Installation

Silk ist das Betriebssystem. ISO laden – kein Aurora nötig.

Installer-ISO (VirtualBox / USB)

Release silk-media-latest · Parts mit bash reassemble.sh zusammenfügen.

Optional: schon Bootc (AMD / Intel)

sudo bootc switch --enforce-container-sigpolicy ghcr.io/wuza0295/silk:latest
sudo systemctl reboot

NVIDIA (Turing / GTX 16xx+, RTX)

sudo bootc switch --enforce-container-sigpolicy ghcr.io/wuza0295/silk-nvidia-open:latest
sudo systemctl reboot

Nach dem Neustart: silk-setup führt durch Stil, Apps und Willkommen.

→ Ausführliche Quickstart-Anleitung

Erste Schritte nach der Installation

silk-welcome              # Kurzhilfe
silk-install datei.exe    # Programme installieren
silk-desktop mac          # Mac-Optik
silk-wallpaper list mac   # Hintergründe
silk-update               # Updates
