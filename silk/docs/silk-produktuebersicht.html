Silk ist ein eigenständiges Linux-Desktop-Betriebssystem für Wechsler von Windows und macOS. Es basiert auf Universal Blue Aurora (KDE Plasma 6) und wird als unveränderliches Bootc-Image ausgeliefert. Optik, Programme und Hardware werden so weit wie möglich vertraut gehalten – ohne macOS oder Windows zu kopieren.

3. Smart-Installer (silk-install)

Silk erkennt Dateiformate und installiert intelligent – Flatpak zuerst, sonst Wine, Waydroid oder Distrobox.

DateiformatVerhalten
.exe / .msiFlatpak-Suche → Wine / Bottles
.apkFlatpak-Suche → Waydroid (Android)
.dmg / .pkg / .appFlatpak-Gegenstück via App-Aliase (z. B. Safari → Firefox)
.AppImageFlatpak → Gear Lever / ~/Applications
.debFlatpak → Ubuntu-Distrobox (silk-ubuntu)
.rpmFlatpak → rpm-ostree oder Fedora-Box (silk-fedora)
.snapFlatpak → Snap in Ubuntu-Box
.flatpak / .flatpakrefflatpak install
$ silk-install --setup-essentials
$ silk-install --setup-gaming
$ silk-install --ensure-boxes
$ silk-install meine-datei.exe

Doppelklick auf Installer-Dateien ist vorkonfiguriert (MIME-Handler).

Installation & Update

# Erstinstallation (von Aurora/Bazzite):
$ sudo bootc switch --enforce-container-sigpolicy ghcr.io/wuza0295/silk:latest
$ sudo systemctl reboot

# System-Update:
$ sudo bootc upgrade && sudo systemctl reboot

# NVIDIA-System:
$ sudo bootc switch --enforce-container-sigpolicy ghcr.io/wuza0295/silk-nvidia-open:latest

9. Grenzen (ehrlich)

  • Kein macOS / Windows: Optik ist angelehnt, kein 1:1-Klon, keine Markenassets
  • Mac-Apps (.app, .dmg) laufen nicht nativ – Silk findet Linux-Ersatz via Flatpak
  • Nicht jedes .exe funktioniert (Anti-Cheat, DRM, spezielle Treiber)
  • Kein Silk auf MacBook-Hardware (weder Intel-Mac noch Apple Silicon)
  • Gaming: Steam/Proton deckt viel ab, aber nicht alles (z. B. manche Online-Shooter)
