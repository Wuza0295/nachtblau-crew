# ALL-INKL Webspace Spiegel

Statische/PHP-Spiegel der auf dem ALL-INKL-Account gehosteten Seiten.

## Partnerprogramm

Der ALL‑INKL Partner-Banner ist eingebunden in:

- `nacht-blau.de/` — alle HTML-Seiten (`index.html`, `index.htm`, `impressum.html`, `datenschutz.html`)
- `hybrixon.com/includes/partner-banner.php` — über den gemeinsamen `footer.php` auf allen Hybrixon-Seiten
- `autictreasures.nacht-blau.de/index.html` — SPA-Shell (gilt für alle Client-Routen)

Zusätzlich erscheint der Banner in der React-App (`NachtBlau Crew`) über Footer und Social-Portal.
