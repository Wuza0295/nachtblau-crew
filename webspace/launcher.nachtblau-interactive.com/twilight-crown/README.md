# Twilight Crown

Top-Down-Action-Adventure im SNES-Zelda-Stil. Rette die **Krone der Dämmerung** (*Twilight Crown*) aus den drei Schattenkrypten.

## Steuerung

| Taste | Aktion |
|-------|--------|
| ↑↓←→ / WASD / Stick / D-Pad | Bewegen · Menü |
| Leertaste / A | Schwert · Reden · Bestätigen |
| Z / B | Item · Bombe |
| E / X | Reden · Truhe (auch A) |
| Start / Esc / P | Pause · Startmenü |
| F / ⛶ | Vollbild |
| ↓ / Y (auf Treppe) | Krypta betreten / verlassen |

## Menüs

- **Startmenü** — Neues Abenteuer, Steuerung, Die Legende
- **Pause** — Fortsetzen, Steuerung, Zum Titel

## Spielziel

1. **Erkunde die Dämmerwelt** — Kronendorf, Kronenhof und die umliegenden Länder
2. **Betritt die drei Krypta** — Felsgrotte, Ruinen, Mine
3. **Finde Karte, Kompass & Schlüssel** in jedem Dungeon
4. **Besiege die drei Bosse** und erwecke die Twilight Crown

## Dungeons

| Eingang | Dungeon | Boss | Belohnung |
|---------|---------|------|-----------|
| Felsgrotte | Schattenkrypta | Schattenwächter | Twilight Crown (Sieg) |
| Verfallene Ruinen | Nebelkathedrale | Nebelgeist | Aether-Klinge |
| Verlassene Mine | Eisengrube | Erzkoloss | Herzcontainer |
