# Twilight Crown

Top-Down-Action-Adventure im SNES-Zelda-Stil. Rette die **Krone der Dämmerung** aus den drei Krypta-Dungeons.

## Steuerung

| Taste | Aktion |
|-------|--------|
| ↑↓←→ / WASD / D-Pad | Bewegen |
| Leertaste / A / ⚔ | Schwert · Topf heben & werfen |
| Z / B / ◆ | Item · Tür · Bombe legen |
| E / X / A | Truhe · NPC · Schild |
| ↓ / Y (auf Treppe) | Krypta betreten / verlassen |

## Spielziel

1. **Erkunde die Welt** — 19 Overworld-Räume, sammle Herzen und Upgrades
2. **Betritt die drei Krypta** — Felsgrotte, Ruinen, Mine
3. **Finde Karte, Kompass & Schlüssel** in jedem Dungeon
4. **Besiege die drei Bosse** und hole die Twilight Crown

## Dungeons

| Eingang | Dungeon | Boss | Belohnung |
|---------|---------|------|-----------|
| Felsgrotte | Schattenkrypta | Schattenwächter | Twilight Crown (Sieg) |
| Verfallene Ruinen | Nebelkathedrale | Nebelgeist | Aether-Klinge |
| Verlassene Mine | Eisengrube | Erzkoloss | Herzcontainer |
